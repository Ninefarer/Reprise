# Tasks that come back

[Documentation](README.md) · [Getting started](GETTING-STARTED.md)

A task can be unfinished without being forgotten. Reprise keeps its lifecycle separate from its start date, deadline, and return timer.

## Choose a place for a task

| Place     | What it means                                                 |
| --------- | ------------------------------------------------------------- |
| Inbox     | Captured, with no organization required yet.                  |
| Do Now    | Work you've explicitly chosen to do now.                      |
| Scheduled | Work planned for a date, with an optional time.               |
| Settled   | Incomplete work deliberately paused until its return time.    |
| Snoozed   | Work temporarily put away for a chosen duration or time.      |
| Waiting   | Work blocked by a response, person, or event.                 |
| Finished  | Completed work, with its history preserved.                   |
| Dropped   | Work you've deliberately let go of, separate from completion. |

Finished tasks can be reopened; Dropped tasks can be restored. Permanent deletion is a separate, confirmed action, not another name for dropping a task.

## Give later a time

**Snooze** for a short pause or a custom return time. **Settle** when you want to stop without losing your place. Settlement can return exactly 24 hours later or at your preferred local time on the following calendar day.

Snoozing and settling preserve the task's original schedule and deadline. Moving to Do Now is an explicit decision, not an automatic response to a reminder.

**Waiting** can have a follow-up time and a reason. A follow-up reminds you to check; it does not mean the dependency has been resolved.

## Review what returns

When a snooze, settlement, or eligible follow-up becomes due, the task enters **Resurfaced**. This is a review queue, not another lifecycle status.

Returned tasks stay there until you handle them. Dismissing a Windows notification does not acknowledge the task or remove it from this queue. Choose a next step: start, schedule, pause again, finish, or drop.

## Schedule and deadline are different

A scheduled start says when you plan to work. A deadline says when the task is due. A return timer says when you want to reconsider it. Changing one should not silently repurpose the others.

## Take a daily look

Daily Review brings together Inbox items, returned tasks, today's plans, overdue tasks, and waiting follow-ups. Open it any time from the sidebar. Its reminder time and quiet hours are editable in Settings.

## When something goes wrong

Closing the window can keep the scheduler running in the tray; quitting stops it. Reprise checks for missed return events on launch. See [Getting started](GETTING-STARTED.md#keep-reminders-running) for reminder behavior and [Architecture](ARCHITECTURE.md) for technical details.
