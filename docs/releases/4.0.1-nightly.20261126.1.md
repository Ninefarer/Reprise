# Reprise 4.0.1-nightly.20261126.1 Nightly

## Changes

- Added Frameless window in Settings > Appearance. Enabled by default; disabling it restores the Windows title bar and border immediately.

## Implementation

- The main window restores its saved frame mode before showing. Quick Capture retains its existing borderless utility window.
- Visual preference updates apply native decorations before persisting and attempt to restore the prior mode if persistence fails. Full settings saves preserve this independent preference.
- The custom top-edge controls are hidden in native-frame mode. The existing glass recipe is reapplied after a frame change.

## Validation

- Frontend toggle and visual tests passed; Rust tests covered default migration, persistence and unrelated preference changes.
- Full frontend suite: 258 passed. Rust: 71 passed and 2 manual checks skipped. Production frontend build, release metadata, formatting and strict Clippy passed.
- Native Windows frame switching and a new installed upgrade were not manually exercised on this packaged build.

## Installation

Install over the existing Nightly installation or use its update feed. Nightly retains its separate installation and task data. The release includes the x64 installer, signature, checksum and update manifest.
