Happy thanksgiving, everyone. I’m thankful for my perseverance and dedication I have (~~as well as sandrone's thick thighs~~). Reprise 4.0 was originally planned to be aimed for January 1st in 2027, but I would be artificially delaying it. The best time to do something is now. A little note - Reprise 4 was actually being worked on in a new internal version of Reprise, "Tachyon". Tachyon aims to always be ahead of reprise releases, and it will always have the newest generation of what Reprise will bring. I never had a proper environment to test anything (~~as I would test things on local nightly, instead of an actual environment oops~~), so this is the purpose of Tachyon - for development testing and newer generations. 4.0 brings much needed fixes, menu reworks, a few new approaches and features, and many more. I hope everyone had much of a comfortable thanksgiving (if you celebrate) as I did. Otherwise, have a wonderful day and enjoy reprise 4! We have *so* much more on the way (ex. Menu position customization, language support other than English) As always, send a PR or open an issue if something is wrong, or you have any more feature ideas. 4.0 will likely have fixes in the coming weeks if I find anything wrong, as I’m hitting the brakes for a while on this one. (p.s for nightly users: Nightly also gets 4.0 and its features as well, such as the date feature which wasn’t in yet.)
