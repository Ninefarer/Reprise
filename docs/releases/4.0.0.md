# Reprise 4.0.0

Previous releases include [Reprise 3.4.7](https://github.com/Ninefarer/Reprise/releases/tag/v3.4.7) and [Reprise 3.4.0 with its original release artwork](https://github.com/Ninefarer/Reprise/releases/tag/v3.4.0).

- ✦ Hold Add to Inbox to send a new task directly to Current, Scheduled, Settled, Snoozed, or Waiting.
- ✦ Turn on Inbox Auto-Settle to move untouched tasks to Settled after 3, 5, or 7 days. Resume returns them to Inbox.
- ✦ Export a portable backup with Takeout, browse for a backup to restore, or create a backup at the end of setup.
- → Task History reads from the first recorded event to the latest and shows which changes Reprise made automatically.
- → Edit Task groups task details and timing and keeps Save and Cancel available while you scroll.
- → Settings uses a section list, and setup shows your progress from Profile through First task.
- → The sidebar is more compact, and Notifications, Ongoing, and Daily Review have refreshed layouts.
- → The main window uses a frameless layout with window controls that appear at the top edge.
- → Drop a task from any active task menu and restore it later from Dropped.
- ▲ Backup files with the same timestamp are distinguishable by filename, and Takeout accepts uppercase backup extensions.
