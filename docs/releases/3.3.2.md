# Reprise 3.3.2

![Additions](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/additions.png?raw=true)

- Reprise now checks for updates and shows available versions in Notifications. You choose when to install.
- Updates are signed and verified before installation, with separate feeds for Stable and Nightly.

Install this version manually once to enable in-app updates. Run the installer over your existing Stable installation; keep your tasks and settings by leaving application data in place.
