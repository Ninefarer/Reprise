# Reprise 3.4.5-nightly.20261119.1 Nightly

Notification visibility, native glass and settings presentation fixes.

## Changes

- Use softer corners on controls, panels and settings tabs while retaining compact Inbox rows and rectangular overview tiles. Preserve the Namecards design and avatar geometry.
- Move Inbox into Hub, and remove decorative colored edge markers from task rows, the editor and active navigation. Unread notification cards use an explicit Unread label instead of a colored border.
- Replace transport, download and signature internals with plain-language update feedback; keep technical details in diagnostics.
- Move section Save/Discard above the active settings panel and keep it visible while scrolling. Retain unsaved-edit guards and section-scoped saving.
- Give the notification panel the same native-glass material and tint as the navigation sidebar. Keep opaque, high-contrast and reduced-transparency fallbacks.
- Keep page scrolling inside the content area so the notification panel reaches the window edges.
- Remove the Windows notification disclaimer from task action notices. Deletion Undo, countdown pauses and locked exits remain intact.
- Show six greeting variants per local time band, with stable wording within each period. Shorten task and setup placeholders and clarify notification empty states.
- Rename the visible profile-card feature to Namecards. Do not include the unrelated local card redesign or sharing changes.

## Implementation

- Add a separate manual update-check command around the existing signed update checker. Explicit checks restore cleared offers and mark existing results unread without changing automatic deduplication.
- Reset notification filters and focus the requested update result. Avoid stealing focus again on later background refreshes.
- Queue a manual update check requested during an automatic check, rather than silently ignoring the click.
- Include project, high-priority, dependency and deadline context in native reminders. Distinguish due-now and overdue deadlines and describe grouped categories instead of using a generic reminder count.
- Preserve channel identities, signature validation, download/install checks, native window composition and reminder scheduling.

## Validation

- All 222 frontend tests passed both in the workspace and in a clean copy of the staged release source. The clean production build passed.
- All 63 Rust tests passed; two existing manual probes were ignored. Formatting and strict Clippy passed.

- Targeted frontend tests cover filtered update-result reveal, retained focus, automatic/manual concurrency, greeting variation and disclaimer removal.
- Backend tests cover restoring cleared manual offers without breaking automatic deduplication, visible unconfigured/error results and category-specific native notification content.
- Native Windows QA displayed the glass notification panel using a synthetic profile. Additional theme/settings visual verification remains outstanding after desktop interaction was interrupted.
