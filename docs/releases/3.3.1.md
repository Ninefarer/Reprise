# Reprise 3.3.1 Hotfix

This fixes a task-editing bug in 3.3.0. Updating is recommended.

![Bugfixes](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/bugfixes.png?raw=true)

- Fixed unsaved task edits being discarded when choosing Do now, Settle, or Finish in task details; your edits now save together with the status change.

Edits already discarded by this bug cannot be recovered by this update. Saved tasks and history are preserved.
