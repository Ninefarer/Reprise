# Reprise 3.4.0 Nightly

Version: `3.4.0-nightly.20261113.1`. This prerelease combines the performance work with the Issue #2 UI/UX overhaul on `develop`.

## Changes

- Stop full task and notification-list reads while native windows are hidden or minimized. Rust scheduling and reminders remain active. Focus/restore retrieves fresh data and recalculates countdowns immediately, preserving unsaved drafts and revision checks.
- Give Quick Capture a settings-only bootstrap, direct task creation and content-sized borderless layout. Remove the decorative plus and place empty-title validation below the field.
- Organize navigation as Hub, Ongoing and Archive. Rename Do Now to Current in presentation only, remove All Tasks from navigation/commands, use an alarm-clock Snooze icon and add explanatory tooltips.
- Replace native selects and date/time popups with shared themed controls, keyboard navigation, type-ahead, explicit Apply/Cancel and optional clearing. Support readable English date entry with minute precision while rejecting invalid or incomplete values.
- Organize Settings into Profile, Appearance, Reminders, Keyboard and About, with a cohesive underline tab bar, narrow-window scrolling and reduced-motion support. Use atomic allowlisted section saves and retain draft protection. Hide redundant Space name fields while preserving stored values.
- Group task editor fields and actions, validate before transitions, and load status-colored history only when expanded.
- Keep notification category selections when their final matching record disappears. Protect nested controls from premature dismissal and remove the redundant unpinned close button while preserving keyboard, hover and pinned behavior.
- Add a command palette shortcut recorder with matching frontend/Rust validation, reserved-command conflict rejection, exact modifiers and reset-to-default.
- Refine Compact spacing, typography, greetings, control names, chevrons, embedded clock buttons and Nightly onboarding popup colors. Separate Stable/Nightly in-app release history and remove the duplicate Settings What's New action.

## Installation

Install the signed Windows x64 NSIS package over the matching Nightly installation, or defer/install the offer from Nightly's in-app Notifications. Nightly retains `com.reprise.nightly` and its separate database. Do not uninstall or delete application data. Older builds without the configured updater feed require manual installation.

This prerelease advances only the Nightly update feed. Stable 3.3.3 remains Latest; no Stable promotion is included.

## Known limitations

- Multi-monitor/DPI combinations, live theme/accessibility changes, exhaustive screen-reader/clipboard/focus paths and every theme/material/control combination remain unverified.
- Real Windows toast display/activation, physical sleep/resume, hours-long suspension and an installed upgrade of this exact candidate were not freshly tested. Native toast delivery was disabled in the hidden-scheduling fixture; a Pending notice is not a banner receipt. Six-hour countdown recovery has simulated regression coverage.
- Adding tasks from every view remains deferred. Undo feedback remains transient rather than becoming notification history. Native glass and task lifecycle identifiers are retained, with no task schema migration.

Implementation and native observations: [Issue #2](https://github.com/Ninefarer/Reprise/issues/2). The tagged source includes `docs/qa/uiux-3.4.0.md` and `docs/qa/window-refresh-suspension-2026-11-13.md` with detailed evidence and remaining checks.
