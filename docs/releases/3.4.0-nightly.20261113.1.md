## Implementation

- Combine the existing native hidden/minimized snapshot suspension and lightweight
  Quick Capture path with all eight Issue #2 UI implementation batches.
- Organize navigation as Hub, Ongoing and Archive. Display `DoNow` as Current
  without changing stored lifecycle identifiers, task timestamps or review semantics.
- Replace native select and date/time popup surfaces with shared custom controls.
  Preserve typed minute precision, explicit Apply/Cancel and optional clearing;
  reject invalid or incomplete dates before converting them to task timestamps.
- Introduce Settings tabs and atomic allowlisted section patches. Preserve
  appearance/avatar updates, other settings and unsaved drafts. Remove Space name
  from the UI while retaining legacy stored values.
- Group task editing fields and action intent, validate transitions, and load
  destination-colored history only when its disclosure is opened.
- Retain notification category choices after their last matching record disappears,
  protect nested popup interaction and retain keyboard/pinned dismissal behavior.
- Record custom command palette shortcuts with exact modifier matching, frontend
  and Rust validation, conflict rejection and reset-to-default.
- Refine Compact spacing, heading typography, navigation tooltips, alarm-clock
  iconography and local-time greeting variation. Keep native Windows composition
  in the existing implementation.
