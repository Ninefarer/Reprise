# Reprise 3.4.2-nightly.20261115.1 Nightly

Avatar crop hotfix from `develop`. Implementation: `7b6938593a9280ee4d99a42008fad7b3336a552e`.

## Implementation

- Replace horizontal/vertical position and zoom sliders with pointer-captured dragging, a non-passive wheel zoom handler, zoom buttons and reset.
- Convert display-space movement into bounded source-image crops for landscape, portrait and zoomed images; preserve the 256px PNG export and explicit Save/Cancel behavior.
- Add keyboard arrow panning, plus/minus zoom and an enlarged responsive circular preview.
- Include Peach and the appearance/shortcut guidance shipped in Stable 3.4.1 since the previous Nightly.

## Validation

- All 206 frontend tests passed locally, including crop bounds, pointer-capture loss, wheel/button/keyboard zoom, reset, cancellation and failed-save coverage.
- Frontend production build passed. Windows WebView mouse dragging, button zoom, wheel zoom and saving were observed using a synthetic image in a separate QA identity.
- Release Actions run Rust tests, formatting, strict Clippy and signed-artifact verification before publication.

## Installation

Use `Reprise.Nightly_3.4.2-nightly.20261115.1_x64-setup.exe` and its matching `.sha256` asset, or update through the Nightly feed. Nightly retains its separate installation and task data. Install over the existing Nightly installation without deleting its data.

## Known limitations

- Touch input and additional Windows display scaling settings were not manually exercised.
