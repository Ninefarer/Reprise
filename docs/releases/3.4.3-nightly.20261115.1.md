# Reprise 3.4.3-nightly.20261115.1 Nightly

Task editor cleanup shared with Stable 3.4.3.

## Implementation

- Move immediate status transitions into Status and timing, ahead of Project and the Save changes footer.
- Rename Make current to Start now; explain Current, settlement using the saved return preference, completion, and saving edits with each action.
- Add an accessible action group and associated guidance.
- Remove the Tags input and Organization fieldset. Keep Project with guidance describing its task-card display and search behavior.
- Retain stored tags and existing search compatibility without a data migration. Lifecycle transitions, return scheduling and channel identities are unchanged.

## Validation

- All 207 frontend tests and the frontend production build passed before release preparation.
- Dialog regression coverage verifies edited values survive transitions and rejected transitions; saving and transitions preserve existing hidden tags.
- Signed release workflows run frontend tests, Rust tests, formatting, strict Clippy and signed-artifact verification before publication.
