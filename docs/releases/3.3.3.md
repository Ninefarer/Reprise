# Reprise 3.3.3 - Hotfix

![Bugfixes](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/bugfixes.png?raw=true)

- Unsaved Settings now offer Save, Discard, or Keep editing before leaving Settings, replaying setup, quitting from the profile menu, or installing an update.
- A sticky save bar shows pending changes; appearance and pictures still save immediately.

This fixes unsaved Settings drafts. Saved tasks and previously saved preferences are unaffected.
