# Reprise 3.4.4-nightly.20261115.2 Nightly

Follow-up to the sliding notices preview, including the previous Nightly's deletion Undo.

## Implementation

- Remove a legacy motion rule that overrode horizontal toast entry and exit animations.
- Animate both each card and its occupied space over 320 ms, so inserting and removing cards moves siblings smoothly instead of changing stack height instantly.
- Show at most three action notices. Additional notices remain queued until an existing notice completes its exit; queued timers start only when shown.
- Auto-dismiss update notices after eight seconds without a drain bar. Hover, keyboard focus and pending Undo pause their timer, as they do for deletion notices.
- Keep deletion notices' 30-second drain bar, transactional Undo and locked exit behavior from the previous Nightly.
- Apply entry and retained, inert exit transitions to in-app notification history. Refreshes do not restart exits; filter changes reset the displayed scope.
- Position the complete action-notice stack beside the notification dock instead of offsetting individual cards.
- Keep notification history records persistent until explicitly managed. Their animations add no automatic history expiry or changes to reminder scheduling.

## Validation

- All 216 frontend tests and the frontend production build passed locally.

- Frontend regression coverage includes visible-stack limits, queued timer promotion, update timeout, hover/resume, exit lockout, retained notification exits and refreshed or returning records.
- The owner checked the isolated native Windows QA build and reported that the behavior worked correctly.
- Release Actions run frontend and Rust tests, formatting, strict Clippy and signed-installer verification before publication.

## Installation

Update through the Nightly feed or install `Reprise.Nightly_3.4.4-nightly.20261115.2_x64-setup.exe` over the existing Nightly installation. Preserve its separate task data. Stable remains at 3.4.3.
