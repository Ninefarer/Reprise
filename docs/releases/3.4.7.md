# Reprise 3.4.7

- ✦ Create and restore local backups from About, with a safety backup before restoration. Backup files contain unencrypted personal data; store them privately.

- ✦ Choose whether Reprise starts with Windows from Reminders settings.

- → Type dates such as `today @ noon`, `tomorrow at 2pm`, `Friday 14:30`, `in 2 hours`, or `3/23/2027`. Ambiguous numeric dates are rejected instead of guessed.

- → The time picker accepts 12-hour and 24-hour times, `noon`, `midnight`, and compact clocks such as `1430`.

- ▲ New or changed scheduled starts must be in the future, preventing accidental immediate reminders for past schedules. Existing overdue tasks remain editable.
