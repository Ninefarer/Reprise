# Reprise 4.0.4 Nightly

## Changes

- Quick Capture uses a full-width destination chooser with two columns at the standard capture window width. Date and time details keep a single column.
- The expanded window uses separate surfaces for the header, entry, and chooser. The Solid capture webview can show transparent gaps when Windows effects and accessibility settings allow it.
- Settings labels the shortcut tab **Keybinds**.

## Validation

- Production frontend build, focused interaction tests, Rust compilation checks, and release metadata checks passed locally. The signed workflow runs the full test suites.
- Native Windows transparency has not been visually verified.

## Installation

Use the Nightly update feed or install over the existing Nightly installation.
