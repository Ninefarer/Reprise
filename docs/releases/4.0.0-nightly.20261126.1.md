# Reprise 4.0.0-nightly.20261126.1 Nightly

Changes since [3.4.6 Nightly](https://github.com/Ninefarer/Reprise/releases/tag/v3.4.6-nightly.20261121.1), including the backup and scheduling improvements from [Stable 3.4.7](https://github.com/Ninefarer/Reprise/releases/tag/v3.4.7).

Integrated application source: [`89c2e86ef9e510e7476691d49871f9ba4033299d`](https://github.com/Ninefarer/Reprise/commit/89c2e86ef9e510e7476691d49871f9ba4033299d) on `develop`. The release tag identifies the final publication commit.

## Changes

- Hold Add to Inbox to select a destination. Scheduled and Snoozed use the same date and time field as Edit Task. Waiting supports a dependency and an optional follow-up.
- Inbox Auto-Settle is disabled by default. Choose 3, 5, or 7 days and preview the eligible count in Reminders. Tasks that qualify move to Settled and stay there until resumed. Multiple moves in one pass produce one notification.
- Task History is grouped by date and starts at the earliest event. It identifies automatic changes where the history records them.
- Edit Task, Settings, onboarding, Notifications, Ongoing, Daily Review, and the sidebar have refreshed layouts. Drop is available from every active task menu.
- The frameless main window reveals controls at the top edge and on keyboard focus. Closing it still follows the existing close-to-tray behavior.
- Nightly picks up the 3.4.7 backup and restore flow and Windows startup setting. This release adds Takeout Save As, a timestamped local backup picker with filenames, and an optional backup after setup. Backup extensions are case-insensitive.
- Nightly also picks up 3.4.7 date and time entry. Try `tomorrow at 2pm`, `Friday 14:30`, `in 2 hours`, or `today @ noon`. Ambiguous numeric dates are rejected. New or changed scheduled starts must be in the future, and existing overdue tasks remain editable.

## Implementation

- Auto-Settle records the transition in task history and persists a distinct settlement mode. Resume clears that mode and starts a fresh Inbox waiting period.
- The capture menu shares Edit Task's date controls. Backend validation also rejects new or changed schedules in the past.
- Backups are stored under the current installation's app-data profile. Restore creates a safety copy before replacement and restarts the app once the restore succeeds. Backup files contain unencrypted personal data.

## Installation

Use the Nightly update feed or run the signed Nightly x64 installer over the existing Nightly installation. Nightly keeps its own installation and task data. The installer is accompanied by its checksum and signature assets.

The versioned release includes `Reprise Nightly_4.0.0-nightly.20261126.1_x64-setup.exe`, its `.sig` and `.sha256` companions, and `latest.json`.

## Known limitations

- Native file dialogs, Windows Snap Layouts and edge resizing still need hands-on verification in the packaged build. Automated window-control checks verify command routing, not desktop behavior.

Report problems through [GitHub Issues](https://github.com/Ninefarer/Reprise/issues/new) without including private task data.
