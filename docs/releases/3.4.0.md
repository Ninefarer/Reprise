# Reprise 3.4.0

A clearer interface, lighter background work, and a better place to return to your tasks. This release brings the 3.3.3 Nightly work and the Issue #2 overhaul to Stable.

![Additions](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/additions.png?raw=true)

- Added themed dropdowns and date/time pickers with keyboard navigation, readable date entry, and Apply, Cancel and Clear actions.
- Added a recorder for your command palette shortcut, with conflict checks and a reset option.
- Added explanatory navigation tooltips and greetings that change throughout the day.

![Changes](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/changes.png?raw=true)

- Reorganized navigation into Hub, Ongoing and Archive; Do Now is now Current, and the redundant All Tasks destination is removed.
- Reworked Settings into Profile, Appearance, Reminders, Keyboard and About tabs, with a moving underline and section Save/Discard controls.
- Grouped task editing fields and separated Save/Cancel from task actions; history stays collapsed until you need it and uses task-state colors.
- Made Quick Capture fit its content, removed the decorative plus, and placed validation beneath the input.
- Stopped hidden and minimized windows from repeatedly loading every task and notification; returning to Reprise refreshes tasks and countdowns immediately while reminders keep running in the tray.
- Made Quick Capture load only the settings it needs instead of fetching all tasks and notifications.
- Refined Compact spacing, typography, control alignment, Snooze iconography and onboarding popup colors while preserving native Clear Glass and Acrylic.
- Simplified the profile menu and removed redundant Space name fields, duplicate What's New controls and unnecessary Settings explanations without deleting saved profile data.
- Improved wording and accessible names across setup, task details, search and the command palette.

![Bugfixes](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/bugfixes.png?raw=true)

- Fixed notification filters losing their selected category when its last matching reminder disappeared.
- Fixed notification panels closing while interacting with nested dropdowns and pickers; keyboard dismissal and pinning remain available.
- Kept release history within the installed Stable or Nightly channel.
- Fixed overlapping Quick Capture validation, misplaced clock buttons and select arrows, and unclear date displays.
- Preserved unsaved task and Settings drafts when hiding or restoring Reprise, with conflicting task saves still rejected safely.
- Made section saves preserve unrelated preferences and kept the 3.3.3 Save, Discard or Keep editing protection when leaving unsaved Settings or installing an update.
- Included the Windows notification-test fix for a missing permission record, while preserving explicit Windows blocks and error reporting.

![Personal note](https://github.com/Ninefarer/Reprise/blob/e59c8dfd1c61f3a6f2da9bb2f2fd1972fa70b5d0/assets/releases/hey.png?raw=true)
