# Reprise 3.4.6-nightly.20261121.1 Nightly

Brings Nightly up to date with Stable 3.4.5 and the 3.4.6 visual hotfix.

## Changes

- Includes the native glass and motion overhaul, independent Theme/Aesthetic/Motion preferences, and namecard finishes and clipboard image sharing shipped in Stable 3.4.5.
- Removes the clipped rectangular shadow beneath task action notifications.
- Aligns the profile menu outline with rounded controls and removes opaque resting button fills that caused visible seams.

## Implementation

- Keeps the toast highlight inside its rounded surface rather than casting an outer shadow through the height-animation clip.
- Gives the profile menu a clipped 16px outline and transparent resting buttons, retaining hover and keyboard-focus feedback.
- Preserves task lifecycle, notification timing, data identities and signed updater configuration.

## Validation

- The user confirmed both visual fixes in the running native development build.
- The hotfix passed 245 frontend tests, 64 Rust tests, formatting, strict Clippy and the production build before its Stable publication.
- The signed Nightly workflow repeats frontend/Rust checks and verifies installer signatures and asset digests before publication.

## Installation

Update through the Nightly feed or install `Reprise.Nightly_3.4.6-nightly.20261121.1_x64-setup.exe` over the existing Nightly installation. The matching `.sha256` and `.sig` assets accompany the installer. Nightly retains its separate installation and task data; Stable remains Latest.

## Known limitations

- The final packaged Nightly installer has not been installed during this release pass; native confirmation used the patched development build.
