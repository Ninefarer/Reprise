# Reprise 3.4.4-nightly.20261115.1 Nightly

Sliding task action notices and deletion Undo. Nightly only, pending manual behavior verification.

## Implementation

- Task update and deletion notices slide in at the lower right and slide out to the right on dismissal, successful Undo or deletion timeout.
- Deletion notices show Deleted with the task title, the subtext "Click undo to revert the deletion.", and a 30-second draining bar. Hover, keyboard focus and pending Undo pause the remaining time; leaving resumes it.
- Exit is locked before animation starts: pointer and keyboard controls are disabled, hover cannot interrupt it, and new actions create separate notices.
- Update notices have no timer. Remove the backend's former 30-second transition-Undo limit while retaining revision and history guards.
- Capture deletion receipts transactionally with the task, owned events, history and notification records. Undo restores these records and reattaches untouched children without overwriting intervening edits.
- Finalize deletion receipts when their notices expire or are dismissed. Undo is scoped to the current app session; restarting discards remaining receipts. Already submitted Windows notifications are not recalled.
- Preserve separate channel identities, native window materials and existing reminder scheduling.

- Backend tests cover restoring task data and owned records, edited-child protection, revision guards, atomic rollback, reminder reconciliation, finalized receipts and session cleanup.

## Installation and verification

Update through the Nightly feed or install `Reprise.Nightly_3.4.4-nightly.20261115.1_x64-setup.exe` over the existing Nightly installation. Keep its separate task data.

## Known limitations

- Native Windows animation appearance and hover behavior await user verification in this Nightly.
- Restoring overdue reminders makes them eligible for the normal scheduler. Undo cannot retract notifications already submitted to Windows.
