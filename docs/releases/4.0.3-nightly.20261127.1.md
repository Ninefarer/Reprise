# Reprise 4.0.3 Nightly

## Changes

- Quick Capture shares the Inbox destination chooser. Hold **Send to...** or press Alt+Down for destinations. Click or press Enter to send to Inbox.
- The capture window grows with the chooser and shared date picker.
- App tooltips share theme colors, hover and keyboard focus delays, and viewport-aware placement. They dismiss on Escape, pointer press, or window changes.

## Validation

- Automated checks cover existing Quick Capture behavior, destination selection, and tooltip interaction. The signed release workflow runs the full suites.

## Installation

Use the Nightly update feed or install over the existing Nightly installation.
